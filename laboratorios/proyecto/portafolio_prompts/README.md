## Descripción del proyecto

El proyecto consiste en desarrollar un sistema de estacionamiento inteligente capaz de identificar los espacios ocupados y libres para facilitar la búsqueda de lugares disponibles y mejorar la organización del estacionamiento.

## Objetivo del portafolio

Documentar los prompts utilizados durante el desarrollo del proyecto, registrando sus objetivos, versiones y archivos correspondientes para mantener evidencia del proceso de elaboración, verificación y mejora de las respuestas generadas mediante inteligencia artificial.
